# Kiran Academy 🎓💻

**Learn Skills. Build Projects. Launch Your Career.**

Kiran Academy is a modern, responsive IT education and career-training website designed to provide students with an interactive platform for exploring courses, career paths, projects, internships, placements, quizzes, and learning resources.

This project was built using **HTML5, CSS3, and Vanilla JavaScript** without using frontend frameworks such as React, Vue, Angular, Bootstrap, or Tailwind CSS.

## 📂 Project Structure

```text
Kiran_Academy_demo/
│
├── home_page.html
├── student-login.html
├── student-dashboard-pro.html
├── style_k_a.css
├── kiran-academy.js
└── README.md
```

### File Description

**`home_page.html`**
Main Kiran Academy website containing the homepage, courses, programs, career paths, internships, placements, quizzes, and other sections.

**`style_k_a.css`**
Contains the complete styling system, responsive layouts, themes, animations, cards, buttons, navigation, and other UI components.

**`kiran-academy.js`**
Handles the interactive functionality of the website, including navigation, quizzes, filters, themes, animations, state management, and other frontend interactions.

**`student-login.html`**
Frontend student login page with form and OTP interface.

**`student-dashboard-pro.html`**
Student dashboard interface for displaying student-related information and learning progress.
